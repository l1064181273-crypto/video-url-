# 已知限制

- 当前仅支持 Apple Silicon Mac。
- 未上架 Chrome Web Store，首次需要通过开发者模式加载解压扩展。
- 首次安装下载量较大，耗时取决于网络速度。
- Chrome 的“每次选择”下载模式会为每个产物分别打开保存窗口。
- 自动配对依赖发行包中固定的扩展 ID，只允许该扩展从浏览器访问配对接口。它不是操作系统级身份凭据；同一 macOS 用户下运行的本地进程本来就能读取该用户的本地配置，因此不在此边界之外提供隔离。
- 如果未来上架 Chrome Web Store，需要先将商店分配的扩展身份与当前固定 ID 对齐；当前 ZIP 面向“加载已解压的扩展程序”。
