Local Video Transcriber Windows 新手使用说明
============================================

这是“一步一步照着做”版本。第一次使用时，请从第 1 步开始，不要跳步。

适用电脑
--------

- Windows 10 22H2 或 Windows 11。
- 64 位 x64 电脑。
- 建议至少预留 10 GB 磁盘空间。
- 第一次安装大约要下载 4.3 GB 文件，通常需要 10 到 60 分钟。
  网速慢时可能更久。只要窗口没有显示红色错误，就继续等待。

重要提醒
--------

- 必须先解压 ZIP，不能直接在压缩包预览窗口中运行。
- 不需要管理员权限，不要选择“以管理员身份运行”。
- 不要手工删除安装目录里的 runtime、config、models 或 app 文件夹。
- 不要用 taskkill 或任务管理器强制结束本程序的服务。


第一部分：第一次安装
====================

第 1 步：把 ZIP 完整解压
-----------------------

1. 找到：
   LocalVideoTranscriber-0.1.1-windows-x64.zip

2. 右键这个 ZIP，点击“全部解压”。
   Windows 11 如果没有看到“全部解压”，先点击“显示更多选项”。

3. 点击“提取”。

4. 打开解压出来的文件夹。
   正确的文件夹里应该能看到：

   启动 Local Video Transcriber.cmd
   新手使用说明.txt
   extension 文件夹
   scripts 文件夹

   如果看不到这些内容，说明你还在压缩包预览窗口里，请回到第 1 步。


第 2 步：开始安装
----------------

1. 双击：

   启动 Local Video Transcriber.cmd

2. 会打开一个黑色窗口。不要关闭它。

3. 第一次安装会自动下载并校验 Python、FFmpeg、Ollama 和语音模型。
   下载总量大约 4.3 GB。

4. 等待黑色窗口出现下面这一行：

   [INFO] WINDOWS_READY: Release is activated and local services are running

5. 看到 WINDOWS_READY 就表示安装成功，而且本地服务已经启动。
   成功后黑色窗口可能很快自动关闭，这是正常现象。

   如果窗口停住并显示：

   Local Video Transcriber could not finish installation.

   就表示安装失败，请不要关闭窗口，先拍下完整错误信息。

如果 Windows 弹出安全提示：

- 先确认 ZIP 来自你信任的发布位置。
- 如果发布者同时提供了 .sha256 文件，请先核对 SHA-256。
- 本项目当前没有 Windows 代码签名，因此 SmartScreen 可能显示未知发布者。
- 只有在来源和 SHA-256 都确认无误时，才点击“更多信息”再点击“仍要运行”。


第二部分：把扩展装进 Chrome
==========================

这一部分第一次只做一次。以后 Chrome 会记住扩展。

第 3 步：打开 Chrome 扩展管理页
------------------------------

1. 打开 Google Chrome。

2. 在最上方地址栏输入：

   chrome://extensions

3. 按 Enter 回车键。

4. 打开页面右上角的“开发者模式”开关。


第 4 步：选择正确的 extension 文件夹
------------------------------------

1. 点击页面左上方的“加载已解压的扩展程序”。

2. 在弹出的文件夹选择窗口里，点击最上方的地址栏。

3. 输入下面这整行：

   %LOCALAPPDATA%\LocalVideoTranscriber\extension

4. 按 Enter 回车键。

5. 点击“选择文件夹”。

注意：

- 要选择安装目录里的 extension 文件夹。
- 不要选择 ZIP 文件。
- 不要选择最外层的 LocalVideoTranscriber-0.1.1 文件夹。
- 扩展 ID 应该是：

  hbcpdfclnpdpiamdelgbpkpiaemmbljg


第 5 步：把扩展固定到 Chrome 工具栏
----------------------------------

1. 点击 Chrome 右上角的拼图图标“扩展程序”。

2. 找到 Local Video Transcriber。

3. 点击旁边的图钉，把它固定到工具栏。

4. 点击 Local Video Transcriber 图标，打开侧边栏。

5. 等待连接状态显示已连接，或者显示：

   已自动配对，无需手动输入 Token

不需要复制 Token，也不要把 Token 发给任何人。


第三部分：转写一个视频
====================

第 6 步：提交视频网址
--------------------

1. 先在浏览器里找到要转写的视频。

2. 复制视频的 HTTP 或 HTTPS 网址。

3. 打开 Local Video Transcriber 侧边栏。

4. 把网址粘贴到“视频 URL”输入框。
   一行放一个网址；一次最多 100 个。

5. 第一次使用时保持默认选项即可。

6. 点击“提交任务”。

注意：当前版本接收视频网址，不是让你选择电脑里的本地视频文件。


第 7 步：等待任务完成
--------------------

1. 任务会出现在“任务”列表。

2. 处理时间取决于视频长度和电脑速度。
   CPU 版本处理长视频可能比视频播放时间更久，这是正常现象。

3. 保持电脑开机，不要让 Windows 休眠。

4. 状态变成“已完成”后，点击“查看详情”。


第 8 步：下载结果
----------------

1. 在任务详情的“文件与预览”区域找到需要的文件。

2. 常用结果：

   - zh-CN.txt：中文纯文本。
   - zh-CN.srt：中文字幕。
   - zh-CN.vtt：网页字幕。
   - source.txt / source.srt / source.vtt：原语言结果。

3. 点击文件旁边的“下载”。

4. 默认会保存到：

   Chrome 下载目录\任务名称

5. 如果希望每次自己选位置，在扩展设置的“下载位置”中选择“每次选择”。


第四部分：以后每次怎么用
======================

1. 打开原来解压出来的文件夹。

2. 双击：

   启动 Local Video Transcriber.cmd

3. 看到 WINDOWS_READY，或者窗口正常自动关闭且没有显示安装失败提示后，
   打开 Chrome。

4. 点击已经固定的 Local Video Transcriber 图标。

5. 粘贴视频网址，点击“提交任务”。

不需要重复安装扩展，也不需要重复输入 Token。


第五部分：停止、检查、升级和卸载
==============================

停止本地服务
------------

1. 打开解压目录里的 scripts 文件夹。

2. 右键 stop.ps1。

3. Windows 11 先点“显示更多选项”，再点“使用 PowerShell 运行”。

4. 看到下面这行表示已经安全停止：

   [INFO] STOP_COMPLETE: Local services have stopped


检查安装状态
------------

1. 打开 scripts 文件夹。

2. 右键 doctor.ps1，点击“使用 PowerShell 运行”。

3. 如果需要向维护人员求助，请截图完整输出。
   不要发送 api-token 文件，也不要发送 Token。


升级到新版本
------------

1. 下载新版本 ZIP。

2. 解压到一个新的普通文件夹，不要覆盖旧 ZIP。

3. 双击新版本的“启动 Local Video Transcriber.cmd”。

4. 安装器会安全升级并保留已有数据。
   如果已安装版本比 ZIP 更新，安装器会拒绝降级。


彻底卸载
--------

只有确定不再需要任务、模型和结果时才执行：

1. 先按“停止本地服务”的步骤安全停止。

2. 打开 chrome://extensions，移除 Local Video Transcriber。

3. 按 Win + R。

4. 输入：

   %LOCALAPPDATA%\LocalVideoTranscriber

5. 按 Enter。

6. 再次确认不需要旧任务和模型，然后删除整个
   LocalVideoTranscriber 文件夹。


第六部分：最常见问题
==================

问题 1：双击后安装失败
---------------------

- 确认网络正常。
- 确认磁盘至少还有 10 GB 空间。
- 不要删除已经下载的文件，重新双击启动文件即可安全重试。
- 保留黑色窗口中的完整错误代码。


问题 2：Chrome 找不到 extension 文件夹
--------------------------------------

- 先确认安装窗口已经显示 WINDOWS_READY。
- 按 Win + R，输入：

  %LOCALAPPDATA%\LocalVideoTranscriber\extension

- 按 Enter。如果文件夹打不开，说明安装尚未成功。


问题 3：扩展显示“本地服务未启动”
--------------------------------

1. 再次双击“启动 Local Video Transcriber.cmd”。
2. 等待 WINDOWS_READY。
3. 回到扩展，点击“重新连接”。


问题 4：出现 START_UNSAFE、STOP_UNSAFE 或 unsafe_or_corrupt
-----------------------------------------------------------

这表示程序不能安全确认进程或端口归属。

- 不要使用 taskkill。
- 不要在任务管理器里强制结束相关进程。
- 不要删除 runtime 或 config 文件夹。
- 运行 doctor.ps1，并把完整输出交给维护人员。


问题 5：提示 11435 端口被占用
----------------------------

通常是另一份 Ollama 正在运行。

- 使用那份 Ollama 自己的退出按钮正常退出。
- 不要用 taskkill 强制结束。
- 然后重新双击启动文件。


问题 6：任务一直处理中
---------------------

- 长视频在 CPU 上可能需要很久。
- 确认电脑没有休眠。
- 再次双击启动文件，确认没有显示安装失败提示。
- 不要反复提交同一个网址。


默认数据位置
============

程序、模型、任务和配置默认保存在：

%LOCALAPPDATA%\LocalVideoTranscriber

转写在本机完成。第一次安装需要联网下载固定依赖和模型；提交在线视频网址时，
程序仍需要从该网址下载视频。Token 由程序自动管理，不会显示在正常使用界面中。
